Scan a real dependency tree

This page is not a simulation. Your submission goes to the SENTINEL server, which resolves every dependency, queries the GitHub Advisory Database package by package, stores the result in SQLite and streams progress back over Server-Sent Events. The same src/core modules power the CLI and the MCP tools.

No credentials required. Nothing is executed — the manifest is parsed, not run.

The server fetches package.json over the GitHub API using its own token. Your browser never holds a credential.

            Same pipeline, no browser
            
Drive it over HTTP

            

              Everything this page does is a plain REST call against the running server. There is no
              private endpoint and no hidden state.
            

          


          

            

              
                

                  Method
                  Path
                  Purpose
                

              
              
                

                  POST
                  /api/scans
                  Queue a scan from repo or manifest. Returns an id.
                

                

                  GET
                  /api/scans
                  List stored scans, newest first.
                

                

                  GET
                  /api/scans/:id
                  Full record: scan, findings, plan, patch and the event log.
                

                

                  GET
                  /api/scans/:id/events
                  SSE stream. Replays history, then follows live.
                

                

                  GET
                  /api/scans/:id/patch
                  The patched manifest as a download.
                

                

                  DELETE
                  /api/scans/:id
                  Delete a scan and its findings.
                

                

                  GET
                  /api/advisories
                  One-off lookup: ?package=lodash&version=4.17.11.
                

                

                  GET
                  /api/status
                  Capability booleans and aggregate statistics.
                

              
            

          


          
curl -X POST localhost:3000/api/scans \
  -H 'content-type: application/json' \
  -d '{"manifest":"{\"dependencies\":{\"lodash\":\"4.17.11\"}}"}'
